# Java 斗地主小游戏

一个基于 Java 控制台实现的经典斗地主扑克牌游戏，采用面向对象设计思想，完整还原了斗地主的核心玩法和规则。

## 项目简介

本项目是一个纯 Java 实现的控制台版斗地主游戏，支持1个玩家与2个电脑AI进行对战。游戏包含完整的发牌、叫地主、出牌、出牌判断、胜负判定等核心逻辑，代码结构清晰，注释详细，非常适合 Java 初学者学习和参考。

## 功能特点

- ✅ 完整的扑克牌生成与洗牌发牌机制
- ✅ 智能电脑AI叫地主和出牌逻辑
- ✅ 支持所有标准牌型判断
- ✅ 实时牌型大小比较
- ✅ 清晰的控制台界面和操作提示
- ✅ 完整的游戏流程控制
- ✅ 胜负判定和积分系统

## 技术栈

- 编程语言：Java 8及以上版本
- 开发工具：IntelliJ IDEA
- 核心技术：面向对象编程、集合框架、枚举、Lambda表达式

## 运行环境

- JDK 1.8 或更高版本
- 任意支持Java的操作系统（Windows/Mac/Linux）

## 快速开始

将项目克隆到本地后，使用Java开发工具打开项目，运行主程序类即可开始游戏。

### 游戏操作

1. 游戏开始后自动洗牌并发牌
2. 轮到你叫地主时，输入1表示叫地主，输入0表示不叫
3. 轮到你出牌时，输入牌的编号，输入0表示不出
4. 按照游戏提示进行操作即可

## 项目结构

项目采用模块化设计，各个类职责明确：

- 扑克牌实体类：定义单张扑克牌的属性和行为
- 牌型枚举类：定义所有支持的牌型
- 玩家抽象类：定义玩家的通用属性和方法
- 人类玩家类：实现人类玩家的操作逻辑
- 电脑AI玩家类：实现电脑AI的决策逻辑
- 游戏核心类：控制整个游戏的流程
- 牌型判断工具类：提供牌型识别和大小比较功能
- 程序入口类：游戏启动入口

## 核心玩法

### 牌型说明

- 单张：任意一张单牌
- 对子：两张点数相同的牌
- 三张：三张点数相同的牌
- 三带一：三张相同点数的牌加一张单牌
- 三带二：三张相同点数的牌加一对牌
- 顺子：五张或更多连续点数的单牌
- 连对：三对或更多连续点数的对子
- 飞机：两个或更多连续点数的三张
- 飞机带翅膀：飞机加同数量的单牌或对子
- 炸弹：四张点数相同的牌
- 王炸：大王加小王

### 游戏流程

1. **发牌阶段**：54张牌，每人17张，剩余3张作为底牌
2. **叫地主阶段**：玩家轮流叫地主，叫到地主的人获得底牌
3. **出牌阶段**：地主先出牌，然后按顺序轮流出牌
4. **胜负判定**：先出完牌的一方获胜
