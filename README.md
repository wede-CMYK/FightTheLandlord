# Java 斗地主小游戏
一个基于 Java Swing 图形界面实现的经典斗地主扑克牌游戏，采用面向对象设计思想，完整还原斗地主全部核心规则与玩法。

## 项目简介
本项目是一个纯 Java 实现的 **Swing 图形界面版** 斗地主游戏，支持1名人类玩家（陈思思）与2名AI玩家（丁兜兜、谭小小）实时对战。
完整实现全部11种标准牌型、智能AI出牌、积分结算、合法出牌校验，界面美观、交互流畅，代码结构规范，适合Java初学者学习参考。

## 功能特点
- ✅ 完整54张扑克牌生成、随机洗牌、自动发牌机制
- ✅ 标准叫地主游戏流程，底牌分配逻辑
- ✅ **11种全套标准牌型识别与校验**（无缺失）
- ✅ 完整牌型大小压制规则
- ✅ **积分对战系统**（胜利加分、失败扣分，实时展示）
- ✅ 高级智能AI（支持全牌型出牌、压牌策略）
- ✅ Swing可视化图形界面，点击选牌、按钮操作
- ✅ 实时展示各玩家剩余牌数、当前积分

- ✅ 完整游戏胜负判定与积分结算

## 游戏操作说明
1. 运行 `App.java` 启动游戏，自动洗牌发牌，每人17张牌，剩余3张底牌
2. 开局选择【叫地主】/【不叫】，不叫则AI随机成为地主
3. 地主获得3张底牌，拥有优先出牌权
4. 点击手牌可**选中/取消选中**（选中后背景变灰）
5. 选中合法牌型后点击【出牌】，无法压制则点击【不出】
6. 率先出完所有手牌的玩家获胜，自动结算积分

## 完整牌型规则（11种全覆盖）
1. 单张：任意一张单牌
2. 对子：两张点数相同的牌
3. 三张：三张点数相同的牌
4. 三带一：三张同点数 + 任意单牌
5. 三带二：三张同点数 + 任意对子
6. 顺子：5张及以上连续单牌（不含2、小王、大王）
7. 连对：3对及以上连续对子（不含2、小王、大王）
8. 飞机：2组及以上连续三张
9. 飞机带翅膀：连续三张 + 对应数量单牌/对子
10. 炸弹：四张点数相同的牌
11. 王炸：小王+大王（最大牌型）

### 牌型大小规则
王炸 > 炸弹 > 普通牌型
普通牌型仅**同牌型可互相压制**，比较最大牌点数

## 积分系统规则
- 玩家胜利：个人+10积分，两名AI各-5积分
- 任意AI胜利：该AI+10积分，玩家-5积分
- 积分实时展示在游戏顶部面板

## AI智能策略
1. 先手出牌：优先出最小合法牌型，保留大牌压制对手
2. 后手压牌：优先匹配上家同牌型最小压制牌
3. 同牌型无法压制时，自动使用炸弹、王炸兜底
4. 无牌可压时自动选择不出
